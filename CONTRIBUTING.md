# Contributing to Chatly

First off, **thank you** for taking the time to contribute! 🎉

## Ways to Contribute

- 🐛 Report bugs via [GitHub Issues](https://github.com/SmartGenzAI1/chatlyclaud/issues)
- 💡 Suggest new features via [GitHub Issues](https://github.com/SmartGenzAI1/chatlyclaud/issues)
- 🔧 Submit pull requests for fixes or features
- ⭐ Star the repo to show support
- 📣 Share it with the Flutter community

## Development Setup

```bash
git clone https://github.com/SmartGenzAI1/chatlyclaud.git
cd chatlyclaud
flutter pub get
flutter run -d chrome --web-port 8080
```

## Pull Request Process

1. **Branch naming:** `feature/short-description` or `fix/short-description`
2. **Commits:** Use [Conventional Commits](https://www.conventionalcommits.org/)
   - `feat:` new feature
   - `fix:` bug fix
   - `refactor:` code refactor
   - `docs:` documentation
   - `style:` formatting
3. **Test your change** before submitting
4. **Update README** if you add a new feature
5. PRs require at least 1 review before merge

## Code Style

- Follow the official [Dart style guide](https://dart.dev/guides/language/effective-dart/style)
- Run `dart format .` before committing
- Run `dart analyze` — no errors allowed

## Reporting Bugs

Please include:
- Flutter version (`flutter --version`)
- Device/platform (Web Chrome, Android, iOS)
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Feature Requests

Open an issue with the `enhancement` label and describe:
- The problem you're trying to solve
- Your proposed solution
- Any alternatives you considered
